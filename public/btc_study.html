📚 Technical Documentation, Data Sources & Calculation Formulas

1. Live & Historical Data Source: Binance Perpetual USDT-Margined Futures API (wss://fstream.binance.com and https://fapi.binance.com/fapi/v1/klines) with automatic failover to Binance Spot API (https://api.binance.com). Zero synthetic or fictional candles are used.

2. Mudrex Fee Schedule Formulas:

  • Taker Fee (Entry / Market SL) = Notional USD × 0.075%
  • Maker Fee (Limit Target Exit) = Notional USD × 0.020%
  • GST = Trading Fees × 18%
  • Funding Charges = (Holding Duration Hours / 8) × 0.01% × Notional USD (Estimated, labeled EST)
  • Slippage Buffer = ₹5.00 per trade
  • Total Charges = Entry Fee + Exit Fee + GST + Funding + Slippage

3. Wallet Accounting Ledger (Zero Double-Counting):

  • Available Margin = Starting Capital + Net Realized P/L - Used Margin
  • Current Wallet Equity = Starting Capital + Net Realized P/L + Unrealized P/L - Est. Exit Charges
  • Double-Counting Prevention: Unrealized P/L is never credited into Net Realized P/L until a simulated position is closed. When closed, margin is released instantly and net realized profit is locked into available cash.

4. Safety Isolation: All simulations are sandboxed within browser memory and local engine state. No live Mudrex, exchange, or Solana engine endpoints are triggered.
